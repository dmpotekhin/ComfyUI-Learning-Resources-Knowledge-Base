## 🧩 LoRA — поиск и использование

**LoRA (Low-Rank Adaptation)** — технология адаптации базовой модели под определённые стили, персонажей, объекты и визуальные концепции.

С помощью LoRA можно расширять возможности модели без необходимости полностью переобучать её.

### 🔥 Основные категории LoRA

| Тип | Назначение |
|---|---|
| 👤 Character LoRA | Конкретные персонажи и внешность. |
| 🎨 Style LoRA | Художественные стили и визуальные эффекты. |
| 💡 Concept LoRA | Отдельные концепции и визуальные элементы. |
| 👕 Clothing LoRA | Одежда и элементы внешнего вида. |
| 🏙️ Object LoRA | Предметы, объекты и окружение. |
| 🏃 Motion LoRA | Управление движением в поддерживаемых архитектурах. |

### ⚠️ Важные моменты

При скачивании LoRA обязательно проверяйте:

- **Base Model** — совместимость с базовой моделью.
- **Trigger Words** — специальные слова для активации LoRA.
- **Weight** — рекомендуемый вес LoRA.
- **File Format** — формат файла, например `.safetensors`.
- **License** — условия использования модели.

> 💡 LoRA для SDXL, FLUX и Wan не являются взаимозаменяемыми. Всегда проверяйте совместимость с конкретной архитектурой.

## 🚀 Рекомендуемый порядок изучения

Если вы начинаете изучать ComfyUI с нуля, рекомендую следующий маршрут.

### 🟢 Level 1 — Basics

- [ ] Посмотреть вводный видеокурс.
- [ ] Разобраться с интерфейсом ComfyUI.
- [ ] Изучить Node, Workflow и связи между нодами.
- [ ] Понять Checkpoint, VAE, Sampler и CLIP.
- [ ] Создать первый Text-to-Image Workflow.
- [ ] Научиться сохранять и загружать Workflow.

### 🟡 Level 2 — Models & LoRA

- [ ] Изучить Hugging Face.
- [ ] Найти подходящую модель на Civitai.
- [ ] Скачать и подключить LoRA.
- [ ] Разобраться с Base Model и Trigger Words.
- [ ] Поэкспериментировать с весами LoRA.
- [ ] Сравнить результаты генерации.

### 🟠 Level 3 — Advanced Workflows

- [ ] Изучить готовые Workflow из официального GitHub.
- [ ] Разобраться с Custom Nodes.
- [ ] Изучить ControlNet.
- [ ] Освоить Image-to-Image.
- [ ] Научиться строить многоэтапные графы.
- [ ] Разобраться с управлением параметрами генерации.

### 🔴 Level 4 — Video Generation

- [ ] Изучить Wan 2.2.
- [ ] Запустить готовый Wan Workflow.
- [ ] Освоить Image-to-Video.
- [ ] Изучить WanVideoWrapper.
- [ ] Попробовать анимацию персонажей.
- [ ] Создать собственный видеоконвейер.

### 🟣 Level 5 — Automation & AI Pipeline

- [ ] Изучить ComfyUI API.
- [ ] Научиться запускать Workflow программно.
- [ ] Разобраться с передачей параметров между этапами.
- [ ] Интегрировать ComfyUI с Python.
- [ ] Изучить автоматизацию генерации изображений и видео.
- [ ] Создать собственный AI Content Pipeline.

## ⭐ Несколько полезных советов

1. Начинайте со стандартных нод, не устанавливайте сразу десятки Custom Nodes.
2. Изучайте чужие Workflow — это один из лучших способов понять архитектуру ComfyUI.
3. Сохраняйте удачные графы и экспериментируйте с их настройками.
4. Ведите собственную библиотеку моделей и LoRA.
5. Проверяйте совместимость моделей и лицензии перед использованием.
6. Изучайте не только генерацию изображений, но и создание полноценного AI-конвейера.
7. Экспериментируйте с локальными моделями — это даёт больше контроля над процессом и данными.

## 🎯 Главная идея

**ComfyUI — это не просто инструмент для генерации картинок, а визуальная среда для построения сложных AI-процессов.**

Изучайте модели, ноды, Workflow, видео и автоматизацию. Самое интересное начинается тогда, когда вы перестаёте просто запускать чужие графы и начинаете создавать собственные AI-конвейеры.
